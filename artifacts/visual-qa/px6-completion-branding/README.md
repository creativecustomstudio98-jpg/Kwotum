# PX6 visual QA — completion i branding

Viewport: 1440 × 1000. Źródło: lokalny harness wykorzystujący produkcyjny
renderer widżetu i jawne manifesty testowe.

1. `01-valid-branding-1440x1000.png` — poprawna nazwa i akcent z automatycznym
   kontrastem;
2. `02-invalid-branding-fallback-1440x1000.png` — niepoprawna projekcja nie jest
   renderowana, działa bezpieczny fallback;
3. `03-no-branding-1440x1000.png` — brak ustawień zachowuje kompletną ścieżkę.

Kadry nie korzystają ze starych zdjęć, stocków ani wcześniejszych obrazów
referencyjnych. Nie są wzorcem marketingowym; dokumentują wyłącznie renderer
PX6 i jego zachowanie awaryjne.
