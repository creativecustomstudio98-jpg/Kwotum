# Visual diff — shared Button

Stan `before` używa poprzedniego brandu `#003B25` i promienia 8 px. Stan
`after` potwierdza na wspólnym komponencie `Button` kolor `#0B684A`, granicę
`#075139`, promień 14 px i wysokość 44 px. Desktop 1440 × 900 oraz mobile
390 × 844 mają 0 px poziomego overflow. Pozostałe komponenty zachowują
dotychczasowe role i geometrię.
