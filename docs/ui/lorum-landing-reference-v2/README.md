# Lorum Landing Reference v2

Pakiet zawiera zamkniętą wizualizację pełnego landing page’a Lorum oraz materiały do kontrolowanej implementacji przez Codexa.

## Najważniejsze pliki

- `LORUM_LANDING_VISUAL_SPEC.md` — pełna specyfikacja.
- `CODEX_IMPLEMENTATION_PROMPT.md` — prompt etapowy.
- `index.html` + `styles.css` — działający prototyp referencyjny.
- `screenshots/lorum-landing-desktop-full.png` — pełny desktop.
- `screenshots/lorum-landing-mobile-full.png` — pełny mobile.
- `screenshots/lorum-board-*` — cztery etapy implementacji desktop/mobile.

## Użycie w repozytorium

Skopiuj cały katalog do:

`docs/ui/lorum-landing-reference-v2/`

Następnie przekaż Codexowi zawartość `CODEX_IMPLEMENTATION_PROMPT.md`.

Nie rozpoczynaj od implementacji całej strony. Najpierw audyt, następnie cztery zamknięte milestone’y.
