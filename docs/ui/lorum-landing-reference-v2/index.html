FAQ

Pytania, które pojawiają się przed pierwszym wdrożeniem.

Odpowiedzi są konkretne — bez obietnic, że jeden widget rozwiąże cały proces sprzedaży.

Masz inne pytanie? Porozmawiajmy
Czy muszę podawać klientowi dokładną cenę?−

Nie. Możesz pokazać przedział, cenę „od”, rekomendowany pakiet, sam wynik kwalifikacji albo ukryć cenę całkowicie.

Czy Lorum działa na WordPressie?+

Tak. Proces można dodać przez blok, shortcode, popup albo przycisk otwierający pełnoekranowy formularz.

Czy proces można dopasować do mojej branży?+

Tak. Szablon jest punktem wyjścia, a pytania, reguły, scoring i wynik można dostosować do konkretnej oferty.

Czy widget spowolni stronę?+

Widget jest ładowany warunkowo i nie powinien wymuszać pobierania panelu ani całej aplikacji SaaS.

Co z RODO i plikami przesyłanymi przez klientów?+

System przewiduje własne treści zgód, retencję, eksport, usuwanie danych i bezpieczny dostęp do załączników.

Czy mogę użyć własnych kolorów i logo?+

Tak. Każda organizacja ma własny motyw widgetu, przy zachowaniu czytelności i dostępności interfejsu.

Czy proces może działać bez strony internetowej?+

Tak. Każdy opublikowany flow może posiadać własny link, który wyślesz w reklamie, wiadomości lub profilu społecznościowym.

Czy można połączyć leady z CRM?+

Tak. Docelowo przez webhooki, eksport i gotowe integracje, przy zachowaniu stabilnego kontraktu API.
