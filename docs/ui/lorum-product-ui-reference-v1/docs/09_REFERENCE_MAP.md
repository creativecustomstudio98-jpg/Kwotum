## Jak czytać referencję

Na każdym screenie oceniaj osobno:

1. shell,
2. siatkę,
3. hierarchy,
4. density,
5. komponenty,
6. statusy,
7. akcje,
8. responsive transformation.

Nie kopiuj demonstracyjnych nazw osób do produkcyjnych danych. Kopiuj sposób przedstawienia informacji.

## Źródło techniczne

`reference/screens.html` i `reference/styles.css` pozwalają sprawdzić dokładną strukturę i wartości użyte do renderu. Są punktem odniesienia, a nie gotowym kodem produkcyjnym do bezmyślnego wklejenia.
