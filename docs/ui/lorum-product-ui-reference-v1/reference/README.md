# Reference files

## Najważniejsze

- `accepted-style-board.png` — zaakceptowany przez właściciela kierunek.
- `boards/` — pięć plansz obejmujących resztę aplikacji.
- `screenshots/` — 20 osobnych widoków do porównań.
- `screens.html` i `styles.css` — deterministyczne źródło renderów.
- `build_reference.py` — skrypt odtwarzający screenshoty i plansze.
- `manifest.json` — lista plików, wymiary i sumy kontrolne.

## Rola HTML/CSS

Kod referencyjny służy do sprawdzenia geometrii i tokenów. Nie powinien być bezmyślnie kopiowany do produkcji, ponieważ nie zawiera realnej logiki, źródeł danych, uprawnień ani frameworkowej architektury aplikacji.
